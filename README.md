# Python Week 8 Final Project: Personal Mini-Toolkit

## Overview
The **Personal Mini-Toolkit** is a menu-driven Python application that bundles three practical utilities into a single interactive console program. It combines variables, input validation, control flow, loops, lists, and functions into a polished, user-friendly tool.

## Included Tools
1. **Quick To-Do List**: Lets users view, append, and manage a dynamic list of daily tasks.
2. **Tip Calculator**: Computes tips and splits totals accurately among groups.
3. **Password Strength Checker**: Audits custom passwords against security criteria (length, digits, uppercase letters).

## How to Run
Ensure you have Python 3 installed, then execute the main script from your terminal:
```bash
python toolkit.py
